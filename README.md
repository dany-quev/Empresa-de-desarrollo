  Empresa de Desarrollo de Software
Este proyecto es un sistema de gestión para una empresa de desarrollo de software que permite gestionar equipos de desarrollo, productos y proyectos.
  Objetivos del proyecto
- Gestionar equipos de desarrollo
- Gestionar productos y proyectos
- Mejorar la eficiencia y productividad de la empresa
  Requisitos del sistema
- C++
- Compilador c++
- Sistema operativo
  Instrucciones de instalación
- Clonar el repositorio
- Compilar el código utilizando c++
- Ejecutar el programa
  Funcionalidades
- Gestión de equipos de desarrollo
- Registrar equipo
- Buscar equipo
- Actualizar equipo
- Eliminar equipo
- Gestión de productos
- Registrar producto
- Buscar producto
- Actualizar producto
- Eliminar producto
