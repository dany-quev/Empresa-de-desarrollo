
Este proyecto es un sistema de gestión para una empresa de desarrollo de software que permite gestionar equipos de desarrollo, productos y proyectos.
  
  Funcionalidades
- Gestión de equipos de desarrollo
- Registrar equipo
- Buscar equipo
- Actualizar equipo
- Eliminar equipo
- Gestión de productos
- Registrar producto
- Buscar producto
- Actualizar producto
- Eliminar producto
